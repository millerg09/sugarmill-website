Step-by-Step Guide: Hosting a GoDaddy Domain on GitHub Pages
This guide outlines how to launch a single-page static website using a domain registered at GoDaddy and free hosting through GitHub Pages.
Phase 1: Set Up Your GitHub Repository
Log into your GitHub account and click the + icon in the top-right corner, then select New repository.
Name the repository (e.g., music-portfolio). Keep the repository setting as Public (required for free accounts using GitHub Pages).
Check the box to Add a README file, then click Create repository.
Phase 2: Upload Your Website Files
Inside your new repository, click Add file > Create new file.
Name the file exactly index.html.
Paste your HTML code (including any third-party Spotify or SoundCloud embed widgets) into the editor.
Scroll to the bottom and click Commit changes to save the file directly to your main branch.
(Optional) Repeat this process to create a style.css file if your design requires separate styling.
Phase 3: Configure GitHub Pages & Custom Domain
In your repository, click the Settings tab (the gear icon along the top menu).
On the left sidebar, scroll down to the "Code and automation" section and click Pages.
Under Build and deployment, ensure the source is set to Deploy from a branch. Under Branch, select main and / (root), then click Save.
Scroll down to the Custom domain section. Type your domain (e.g., yourdomain.com) into the box and click Save. This creates a file named CNAME in your repository automatically.
Phase 4: Configure DNS Records at GoDaddy
Log into your GoDaddy Control Panel and navigate to your Domain Portfolio, then click on your domain to open DNS Management.
Add the A Records: You need to point your root domain to GitHub’s apex servers. Add four separate records with the following details:
Type: A | Name: @ | Value: 185.199.108.153
Type: A | Name: @ | Value: 185.199.109.153
Type: A | Name: @ | Value: 185.199.110.153
Type: A | Name: @ | Value: 185.199.111.153
Add the CNAME Record: This directs your www subdomain to your GitHub domain name.
Type: CNAME | Name: www | Value: yourusername.github.io. (Replace with your exact GitHub username and ensure the trailing dot is included if GoDaddy requires it).
Delete any conflicting default A or CNAME records that point to GoDaddy placeholders.
Phase 5: Enforce Secure HTTPS
Return to your GitHub repository Settings > Pages dashboard.
Wait a few minutes for the DNS changes to propagate worldwide and for GitHub to issue your free SSL certificate.
Check the box for Enforce HTTPS once it becomes clickable. Your site is now live and secure.
